
# Tebak Angka

Aplikasi Android sederhana untuk permainan tebak angka yang dibuat untuk memenuhi tugas UTS Mobile Programming.

## Anggota Kelompok

1. Tio Alan Kurniawan - 245314114
2. Tumba TL Sihombing - 245314001

## Deskripsi

Aplikasi ini memilih angka secara acak dari 0 sampai 100. Pengguna harus menebak angka tersebut berdasarkan petunjuk yang diberikan oleh aplikasi.

## Fitur

- Menebak angka dari 0 sampai 100.
- Petunjuk angka terlalu besar atau terlalu kecil.
- Sistem skor.
- Memulai permainan baru.

## Cara Menjalankan

1. Buka project di Android Studio.
2. Tunggu proses Gradle Sync selesai.
3. Hubungkan perangkat Android atau jalankan emulator.
4. Tekan tombol Run untuk menjalankan aplikasi.
